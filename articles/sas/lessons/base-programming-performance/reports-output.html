01

PROC PRINT で一覧レポートを作る

PROC PRINT は最も基本的な一覧出力です。表示列、合計、条件、ID、BY、ラベル表示を組み合わせて、必要な形の一覧表を作ります。

表示する行・列・合計を指定する — PROC PRINT

基本形: proc print data=データセット名; var 表示変数; run;

  • proc sort ... by region customer_id; は、BY レポートの前提として地域・顧客順に並べる。
  • title と footnote はレポートの見出しと脚注を設定する。
  • proc print ... noobs label split="*"; は、Obs列を隠し、ラベルを列見出しに使い、* で見出しを改行する。
  • id、var、sum、where で、識別列・表示列・合計・行条件を指定する。
/* BYレポートの前に地域、顧客IDの順で並べ替える */
proc sort data=work.orders_clean out=work.orders_report;
  by region customer_id;
run;

/* 表題と脚注を設定し、地域別の一覧表を作る */
title "Orders by Region";
footnote "Generated for certification practice";

proc print data=work.orders_report noobs label split="*";
  by region;
  id customer_id;
  var order_date product amount;
  sum amount;
  where amount > 0;
  label order_date = "Order*Date"
        amount = "Order*Amount";
run;

/* 後続の出力へ引き継がないよう表題と脚注を解除する */
title;
footnote;

出力結果例

/* NOOBSによりObs列はなく、ラベル内の*で見出しが改行される */
Region=East

customer_id    Order       product    Order
               Date                   Amount
C001           2026-08-01  Desk        8,000
C002           2026-08-03  Chair       7,000
                                      ------
                                      15,000

Print Details

PROC PRINT は「表示の制御」を細かく指定する

一覧表では、単に全行を出すのではなく、問題文に合わせて列順、識別列、合計、列見出し、グループ単位を制御します。

指定なしの表示

  • VARを省略すると全変数、WHEREを省略すると全オブザベーションを表示する。
  • NOOBSを付けなければ、左端にオブザベーション番号のObs列が表示される。

VAR と ID

  • VAR は表示する変数と順序を決める。
  • ID は各行を識別する列を左側に置く。

SUM と BY

  • SUM は数値列の合計を出す。
  • BY レポートは事前ソートが必要。

LABEL と SPLIT=

  • LABEL は列見出しとしてラベルを使う。
  • SPLIT= は列見出しを指定文字で折り返す。

NOOBS

  • 左端に自動表示されるObs列を表示しない。
  • IDで業務上の識別列を表示する場合に組み合わせやすい。

指定されたオブザベーションだけ確認する — FIRSTOBS= / OBS=

基本形: proc print data=データセット(firstobs=開始番号 obs=終了番号); run;

FIRSTOBS=は読み始めるオブザベーション番号、OBS=は読み終える番号です。同じ番号を指定すると、その1行だけを確認できます。番号は現在の並び順に対する位置なので、先に指定どおり並べ替えます。

/* 並べ替え後の148番目の商品名だけを表示する */
proc print data=work.sortedshoes(firstobs=148 obs=148) noobs;
  var product;
run;

/* 並べ替え後の130番目の地域だけを表示する */
proc print data=work.sortedshoes(firstobs=130 obs=130) noobs;
  var region;
run;

出力結果例

/* 148番目の1行だけが表示される */
product
Slipper

region
Pacific

02

FREQ / MEANS / UNIVARIATE で検証する

これらの PROC はレポート作成だけでなく、データ品質の確認にも使います。カテゴリの種類、欠損、外れ値、合計値をすばやく確認します。

カテゴリの件数を確認する — PROC FREQ

基本形: proc freq data=データセット名; tables 変数; run;

一元表でカテゴリ別件数、アスタリスクで変数を結んだ二元表でカテゴリの組み合わせを確認します。MISSINGを付けると欠損値も集計します。

/* 地域とステータスの組み合わせ別件数を確認する */
proc freq data=work.orders_clean nlevels;
  tables region*status / missing;
run;

基本統計量を集計する — PROC MEANS

基本形: proc means data=データセット名 統計量; class 分類変数; var 数値変数; run;

N、MEAN、SUM、MIN、MAXなどを指定し、CLASSの値ごとに数値変数を集計します。

/* 地域別に金額の基本統計量を集計する */
proc means data=work.orders_clean n mean sum min max maxdec=2;
  class region;
  var amount;
run;

集計レベルと出力データを指定する — WAYS / OUTPUT

集計レベル: ways 分類変数の組合せ数;

データセット出力: output out=出力データ 統計量= / autoname;

  • WAYS 1はCLASS変数を1つずつ使った集計、WAYS 2は2変数の組合せで集計する。
  • OUTPUT OUT=は表示結果とは別に、統計量をSASデータセットとして保存する。
  • AUTONAMEはamount_Meanのように元変数名と統計量を組み合わせた列名を付ける。
/* 地域別、ステータス別、両者の組合せで集計する */
proc means data=work.orders_clean n mean sum;
  class region status;
  ways 1 2;
  var amount;
  output out=work.amount_summary mean= sum= / autoname;
run;

分布と極値を詳しく確認する — PROC UNIVARIATE

基本形: proc univariate data=データセット名; var 数値変数; run;

基本統計量に加えて、分位点や極端な値など、数値変数の分布を詳しく確認します。

/* 金額の分布と極端な値を詳しく確認する */
proc univariate data=work.orders_clean;
  var amount;
run;

Frequency

PROC FREQ はカテゴリ確認と検算の中心

PROC FREQ は一元表と二元表を作るだけでなく、カテゴリの種類、欠損、想定外の値を見つける検証用 PROC として使います。

度数表の表示を調整する — NLEVELS / ORDER= / MISSING

基本形: proc freq data=データセット名 nlevels order=並び順; tables 変数 / missing; run;

  • nlevels は、各変数に何種類の値があるかを表示する。
  • order=freq は、度数の多い順に結果を並べる。
  • tables region status は一元表、region*status は二元表を作る。
  • / missing は欠損値も度数表に含める。
/* 欠損を含め、度数の多い順にカテゴリを確認する */
proc freq data=work.orders_clean nlevels order=freq;
  tables region status region*status / missing;
run;

NLEVELS

  • 変数ごとの水準数を確認する。
  • 表記ゆれや想定外カテゴリの発見に使う。

ORDER=

  • 度数表の表示順を制御する。
  • 頻度順やデータ順など、問題文の指定に合わせる。

二元表

  • region*status のように、2 つのカテゴリの組み合わせを確認する。
  • 抽出条件や分類変数の作成ミスを見つけやすい。

Summary

PROC MEANS と UNIVARIATE は、集計と異常値確認で使い分ける

PROC MEANS は基本統計量やクラス別集計に強く、PROC UNIVARIATE は極値や欠損、分布の確認に向きます。レポート作成だけでなく、作ったデータセットの検算にも使います。

集計と分布確認を使い分ける — MEANS / UNIVARIATE

MEANS: proc means data=データセット名 統計量; class 分類変数; var 数値変数; run;

UNIVARIATE: proc univariate data=データセット名; var 数値変数; run;

  • n、nmiss、mean、sum などは出力する統計量を指定する。
  • class region status; は地域・ステータス別に要約する。
  • var amount; は統計量を計算する数値変数を指定する。
  • PROC UNIVARIATE は、極値や分布を詳しく確認するときに使う。
/* 地域・ステータス別に件数、欠損、要約統計を確認する */
proc means data=work.orders_clean n nmiss mean median sum min max maxdec=2;
  class region status;
  var amount;
run;

/* 同じ金額変数の分布と極値を詳しく確認する */
proc univariate data=work.orders_clean;
  var amount;
run;
MEANS

集計の確認

件数、欠損、平均、合計、最小、最大を素早く見る。CLASS でカテゴリ別の要約を作る。

UNIVARIATE

極値と分布

極端な値や欠損を見つけたいときに使う。データ品質確認の最後に役立つ。

要約表の対象と表示を調整する — NWAY / MISSING / MAXDEC=

基本形: proc means data=データ nway missing maxdec=桁数; class 分類変数; var 数値変数; output out=出力 統計量= / autoname; run;

  • NWAYは、すべてのCLASS変数を組み合わせた最も細かい集計レベルだけを出す。
  • MISSINGは、CLASS変数の欠損値を1つの分類として集計に含める。
  • MAXDEC=は表示する小数点以下の最大桁数を指定する。
  • OUTPUT OUT=の出力には、集計レベルを示す_TYPE_と、そのグループの行数を示す_FREQ_が自動的に含まれる。
/* 地域×ステータスの最も細かい組み合わせだけを集計する */
proc means data=work.orders_clean nway missing maxdec=0;
  class region status;
  var amount;
  output out=work.amount_nway mean= sum= / autoname;
run;

出力結果例

/* _TYPE_=3は2つのCLASS変数を両方使った集計を表す */
region    status    _TYPE_    _FREQ_    amount_Mean    amount_Sum
East      Open         3          4          12500         50000

CLASSが2つあると、集計レベルを選べる

WAYS 1
regionstatus＋regionstatus

1変数ずつの集計

WAYS 2／NWAY
regionstatus→East × Open

2変数を組み合わせた最も細かい集計

結果の検算

条件別の件数と平均を確認する

分類変数を作った後は、度数表で各区分の件数を確認し、WHEREで対象区分を絞って要約統計を求めます。公式サンプル問題のように、作成したデータを別のPROCで検算する流れです。

区分別件数を求める — PROC FREQ

基本形: proc freq data=データセット名; tables 区分変数; run;

区分ごとの行数を確認します。合計件数が入力データの行数と一致するか、境界値や欠損値が意図しない区分へ入っていないかも確認します。

/* 売上区分ごとのオブザベーション数を確認する */
proc freq data=work.shoerange;
  tables salesrange;
run;

出力結果例

/* 出力からLower区分の行を抜粋 */
SalesRange    度数
Lower          288

対象区分の平均を求める — WHERE + PROC MEANS

基本形: proc means data=データセット mean maxdec=0; where 区分変数="値"; var 数値変数; run;

WHEREで集計対象を限定し、MEANで平均、MAXDEC=0で整数表示にします。

/* Middle区分だけに絞ってSalesの平均を求める */
proc means data=work.shoerange mean maxdec=0;
  where salesrange = "Middle";
  var sales;
run;

出力結果例

/* 平均は小数点以下を表示せず135127となる */
変数      平均
Sales    135127

03

PROC FORMAT とラベルで出力を読みやすくする

PROC FORMAT は値の表示を変えます。保存値そのものは変えず、レポート上の見え方を変える点が重要です。

値に表示用の区分名を付ける — PROC FORMAT

基本形: proc format; value format名 範囲="表示文字"; run;

  • proc format; でユーザー定義 format を作る。
  • value amountgrp は数値用の format 名を定義する。
  • VALUEで定義するときの名前にはピリオドを付けず、FORMATで適用するときはamountgrp.のように末尾へピリオドを付ける。
  • low-<3000 は 3000 未満、3000-<10000 は 3000 以上 10000 未満を表す。
  • format amount amountgrp.; は、保存値を変えずに表示だけグループ名へ変える。
/* 金額をLow・Middle・Highで表示するformatを作る */
proc format;
  value amountgrp
    low-<3000 = "Low"
    3000-<10000 = "Middle"
    10000-high = "High";
run;

/* 作成したformatと変数ラベルを一覧表へ適用する */
proc print data=work.orders_clean label;
  var customer_id order_date amount;
  format amount amountgrp.;
  label customer_id = "Customer ID"
        order_date = "Order Date";
run;
CNTLIN=

試験範囲には、データセットから format 定義を読み込む CNTLIN= も含まれます。大量のコードを手書きせず、定義表から format を作る仕組みです。

CNTLIN

format 定義をデータセットから作る

CNTLIN= は、format 定義をデータとして持ち、PROC FORMAT に読み込ませる方法です。大量の範囲やラベルを手書きしないときに使います。

定義データからformatを作る — CNTLIN=

基本形: proc format cntlin=定義データセット; run;

  • fmtname は作成する format 名、type は文字用か数値用かを指定する。
  • start と end は範囲の下限・上限を表す。
  • label は表示する文字列を指定する。
  • hlo は LOW や HIGH などの特殊範囲を指定する。
  • proc format cntlin=... で、その定義データセットから format を作る。
/* formatの範囲と表示文字を定義データとして作る */
data work.amount_format;
  length fmtname $ 12 start 8 end 8 label $ 12 type $ 1 hlo $ 1;
  fmtname = "amountgrp";
  type = "N";

  hlo = "L"; start = .; end = 2999; label = "Low"; output;
  hlo = ""; start = 3000; end = 9999; label = "Middle"; output;
  hlo = "H"; start = 10000; end = .; label = "High"; output;
run;

/* 定義データを読み込んでformatを作る */
proc format cntlin=work.amount_format;
run;
確認ポイント

FMTNAME、START、END、LABEL、TYPE の役割を押さえます。文字 format なら TYPE="C"、数値 format なら TYPE="N" です。範囲の LOW / HIGH は HLO で表します。

04

SASシステムオプションでレポート全体を調整する

OPTIONSは個別のPROCではなく、後続の出力全体へ作用するグローバルステートメントです。日付・ページ番号・用紙方向などをまとめて制御します。

日付・ページ番号・用紙方向を設定する — OPTIONS

基本形: options nodate nonumber orientation=landscape;

  • NODATEは出力日時、NONUMBERはページ番号を非表示にする。
  • ORIENTATION=LANDSCAPEは横向き、ORIENTATION=PORTRAITは縦向きにする。
  • 設定は後続の出力にも残るため、必要な処理が終わったら元の設定へ戻す。
/* 以降のレポートから日付とページ番号を除き、横向きにする */
options nodate nonumber orientation=landscape;

proc print data=work.orders_clean noobs;
  var customer_id order_date amount;
run;

/* 後続のレポート用に標準的な設定へ戻す */
options date number orientation=portrait;

05

ODS と EXPORT でファイルへ出す

ODS は SAS の出力先を制御します。HTML、PDF、RTF、Excel などの出力に使います。単純な外部データファイル作成には PROC EXPORT も使えます。

PROCの結果をレポートファイルへ出す — ODS

基本形: ods 出力形式 file="ファイルのパス" style=スタイル名;

ODSはPROCが作る表やグラフをHTML、PDF、RTFなどへ送ります。処理後は、開いた形式に対応するods 出力形式 close;で閉じます。

/* PDF出力を開き、地域別集計を保存する */
ods pdf file="/home/user/report.pdf" style=journal;

proc means data=work.orders_clean n mean sum maxdec=2;
  class region;
  var amount;
run;

/* PDF出力を閉じる */
ods pdf close;

ODSは「開く → PROCを実行 → 閉じる」

1. 開くods pdf file=...;
→
2. 結果を送るproc means ...;
→
3. 閉じるods pdf close;

開いている間に実行したPROCの出力がファイルへ入ります。閉じ忘れると、ファイルが完成しない・後続結果まで入る原因になります。

Webページとして出す — ODS HTML

基本形: ods html file="出力.html" style=スタイル名; ... ods html close;

HTMLはブラウザで閲覧するレポートを作ります。STYLE=は表や見出しのデザインを指定します。

/* 一覧表をHTMLファイルへ保存する */
ods html file="/home/user/orders.html" style=htmlblue;
proc print data=work.orders_clean noobs;
run;
ods html close;

文書として出す — ODS RTF

基本形: ods rtf file="出力.rtf" style=スタイル名; ... ods rtf close;

RTFはWordなどの文書ソフトで開いて編集できるレポートを作ります。

/* 地域別の要約統計をRTFファイルへ保存する */
ods rtf file="/home/user/summary.rtf" style=journal;
proc means data=work.orders_clean   mean sum;
  class region;
  var amount;
run;
ods rtf close;

Excelブックとして出す — ODS EXCEL

基本形: ods excel file="出力.xlsx" options(sheet_name="シート名"); ... ods excel close;

ODS EXCELはPROCの一覧表や集計表を、Excelで開けるレポートとして保存します。データセットそのものを書き出すXLSXエンジンとは目的が異なります。

/* 地域別集計をSummaryシートへ出す */
ods excel file="/home/user/summary.xlsx"
          options(sheet_name="Summary");
proc means data=work.orders_clean mean sum;
  class region;
  var amount;
run;
ods excel close;

PowerPointとして出す — ODS POWERPOINT

基本形: ods powerpoint file="出力.pptx" style=スタイル名; ... ods powerpoint close;

PROCの結果をPowerPointファイルへ出力します。出力先を開いた後にPROCを実行し、最後に同じ出力先を閉じます。

/* 地域の度数表をPowerPointへ保存する */
ods powerpoint file="/home/user/regions.pptx" style=powerpointlight;
proc freq data=work.orders_clean;
  tables region;
run;
ods powerpoint close;

PROCの表をCSVとして出す — ODS CSV

基本形: ods csv file="出力.csv"; ... ods csv close;

ODS CSVはPROCが作った表をCSVへ出します。元のSASデータセットをそのまま外部データへ変換する場合はPROC EXPORTを使います。

/* PROC PRINTの表をCSVファイルへ保存する */
ods csv file="/home/user/orders_report.csv";
proc print data=work.orders_clean noobs;
run;
ods csv close;

SASデータセットをCSVへ書き出す — PROC EXPORT

基本形: proc export data=データセット名 outfile="ファイルのパス" dbms=csv replace; run;

DATA=に出力元、OUTFILE=に保存先を指定します。REPLACEは既存ファイルの上書きを許可します。

/* SASデータセットをCSVファイルへ書き出す */
proc export data=work.orders_clean
            outfile="/home/user/orders_clean.csv"
            dbms=csv
            replace;
run;

主なDBMS指定

指定出力形式追加指定
DBMS=CSVカンマ区切り通常はそのまま使用
DBMS=TABタブ区切り通常はそのまま使用
DBMS=DLM任意の区切り文字delimiter="|";など
DBMS=JMPJMPデータファイル利用環境の対応を確認

Excelブックへシートを書き出す — XLSXエンジン

基本形: libname ライブラリ名 xlsx "Excelファイルのパス";

Excelブックをライブラリとして割り当て、データセット名をシート名として書き出します。最後にCLEARで割り当てを解除します。

/* Excelブックを出力先ライブラリとして割り当てる */
libname excelout xlsx "/home/user/orders.xlsx";
data excelout.orders_clean;
  set work.orders_clean;
run;
/* Excelブックのライブラリ割り当てを解除する */
libname excelout clear;

Output Checks

ODS と EXPORT は「何を出すか」で選ぶ

ODS は PROC の結果を人が読むレポートとして出す仕組みです。PROC EXPORT と XLSX エンジンは、データセットを外部データとして渡すときに使います。

ODS HTML / PDF / RTF

  • ブラウザ向け、固定レイアウト、編集可能な文書としてPROCの結果を保存する。
  • 開いた出力先は、最後に対応する close で閉じる。

ODS EXCEL / POWERPOINT / CSV

  • PROCの表をExcelブック、プレゼンテーション、CSVへ保存する。
  • 元データをそのまま受け渡すCSVにはPROC EXPORTを使う。

PROC EXPORT

  • シンプルな生データファイルを作る。
  • DBMS=csv、DBMS=tab、DBMS=dlm などを指定する。

XLSX エンジン

  • Excel ワークブックをライブラリのように扱ってデータを書き出す。
  • 複数シートへ出したい場合に、メンバ名をシート名として使える。

レポート作成からファイル出力までの総合確認テスト

空欄を埋めて、一覧、度数、要約統計、format、ODSレポート、外部ファイル出力を行う一連のコードを完成させてください。

/* BYレポート用に地域順へ並べ替える */
proc sort data=work.orders_clean out=work.orders_report;
   region;
run;

/* 表題と脚注を付け、一覧表を作る */
 "Orders by Region";
 "Positive Amounts";
 data=work.orders_report  label ="*";
   region;
   customer_id;
   order_date amount;
   amount;
   amount > 0;
run;
title;
footnote;

/* カテゴリ別件数を確認する */
 data=work.orders_clean;
   region / missing;
run;

/* 地域別の件数・平均・合計をPDFへ出す */
 pdf file="/home/user/summary.pdf" ;
 data=work.orders_clean n mean sum;
   region;
   amount;
run;
ods pdf ;

/* データをCSVへ書き出す */
 data=work.orders_clean
            ="/home/user/orders.csv"
            =csv
            ;
run;
/* ユーザー定義formatを作る */
proc format;
   score low-<60="Fail" 60-high="Pass";
run;

/* 定義データセットからformatを作る */
proc format ;
run;

/* ユーザー定義formatをピリオド付きで適用する */
proc print data=work.scores ;
  format test ;
run;

/* 1変数・2変数の分類レベルで集計結果を保存する */
proc means data=work.orders_clean mean sum;
  class region status;
   1 2;
  var amount;
   out=work.amount_summary mean= sum= / autoname;
run;

/* PROCの結果をExcel、PowerPoint、CSVへ出す構文 */
ods  file="/home/user/report.xlsx";
ods excel close;
ods  file="/home/user/report.pptx";
ods powerpoint close;
ods  file="/home/user/report.csv";
ods csv close;
ods  file="/home/user/report.html";
ods html close;
ods  file="/home/user/report.rtf";
ods rtf close;
/* 水準数を表示し、度数の多い順に欠損も含めて集計する */
proc freq data=work.orders_clean  ;
  tables region*status / ;
run;

/* 分布、欠損、極値を詳しく確認する */
 data=work.orders_clean;
  var amount;
run;

/* パイプ区切り、JMP、タブ区切りファイルを書き出す */
proc export data=work.orders_clean outfile="/home/user/orders.txt" dbms= replace;
  ="|";
run;

proc export data=work.orders_clean outfile="/home/user/orders.jmp" dbms= replace;
run;

proc export data=work.orders_clean outfile="/home/user/orders.tsv" dbms= replace;
run;

/* XLSXエンジンでExcelブックへデータを書き出す */
libname excelout  "/home/user/orders.xlsx";
data excelout.orders_clean;
  set work.orders_clean;
run;
libname excelout ;
/* 並べ替え後の148番目だけを確認する */
proc print data=work.sortedshoes( ) noobs;
  var product;
run;

/* 同じデータの130番目から地域だけを確認する */
proc print data=work.sortedshoes( ) noobs;
  var region;
run;

/* レポート全体の日付とページ番号を除き、横向きにする */
options   orientation=;

/* Middle区分だけの平均を整数表示で求める */
proc means data=work.shoerange mean ;
   salesrange="Middle";
  var sales;
run;

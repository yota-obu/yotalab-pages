データ構造へのアクセスと作成

ライブラリを割り当て、既存データを読み、外部ファイルを取り込み、結合し、日付や行列制御まで扱う領域。

← SAS Base Programming 学習トップへ

Goal

データの読み込みから結合・確認まで

一時・永久データセットの作成、CSV・Excelの読み込み、データの結合、行・列の抽出、日付変換、構造確認を扱います。

01

一時・永久データセットとライブラリ

SAS データセットは、セッション中だけ使う一時データセットと、ファイルとして残す永久データセットに分かれます。work ライブラリに作るものは一時、cert.sales のように自分で割り当てたライブラリに作るものは永久です。

ライブラリを割り当てる — LIBNAME

基本形: libname ライブラリ名 "フォルダのパス";

指定したフォルダに、SAS プログラム内で使うライブラリ名を割り当てます。

/* フォルダに cert というライブラリ参照名を割り当てる */
libname cert "/home/user/cert";

一時データセットを作る — DATA

基本形: data work.データセット名;

省略形: data データセット名;

ライブラリ名を省略した場合も、自動的に work ライブラリへ作成されます。どちらも一時データセットのため、SAS のセッションを終了すると削除されます。

/* WORK を明示する書き方 */
data work.sales_temp;
  set cert.sales_raw;
run;

/* ライブラリ名を省略しても WORK に作られる */
data sales_temp;
  set cert.sales_raw;
run;

永久データセットを作る — DATA

基本形: data ライブラリ名.データセット名;

指定したライブラリ内に永久データセットを作成します。ライブラリが参照するフォルダにファイルとして残ります。

/* cert ライブラリに永久データセットを作る */
data cert.sales_clean;
  set work.sales_temp;
run;

既存データセットを読み込む — SET

基本形: set ライブラリ名.データセット名;

指定した既存の SAS データセットを読み込みます。読み込んだ行を DATA ステップで処理し、新しいデータセットへ出力します。

/* 既存の sales_raw を読み込む */
data work.sales_temp;
  set cert.sales_raw;
run;

データセットの構造を確認する — PROC CONTENTS

基本形: proc contents data=ライブラリ名.データセット名;

指定したデータセットの変数名、型、長さ、format などの構造を確認します。

/* データセットの構造を確認する */
proc contents data=cert.sales_clean;
run;

オブザベーション数  250

表示項目意味確認すること
データセット名対象のライブラリ名とデータセット名調べたいデータセットが選ばれているか
オブザベーション数データの行数行数が想定どおりか。違う場合は抽出条件や重複を確認する
変数の数データの列数必要な変数の不足や、不要な変数の混入がないか
タイプ変数が文字型か数値型か計算する値や SAS 日付などが想定した型になっているか

ライブラリのデータセット一覧を調べる — _ALL_ / NODS

基本形: proc contents data=ライブラリ名._all_ nods; run;

ライブラリ名._ALL_は、そのライブラリにあるすべてのデータセットを対象にします。NODSは各データセットの変数詳細を省略し、ライブラリのディレクトリ情報だけを表示します。全データセットの変数情報も確認する場合は、NODSを外します。

/* CERTライブラリ内の全データセットをまとめて調べる */
proc contents data=cert._all_ nods;
run;

出力結果例

/* NODSにより、個別の変数詳細ではなくデータセット一覧が表示される */
CERTライブラリのディレクトリ

番号  メンバー名     メンバータイプ
1     CUSTOMERS      DATA
2     SALES_CLEAN    DATA

確認テスト

問題 1. data sales; で作成されるデータセットはどれですか。

問題 2. PROC CONTENTS の出力で確認できないものはどれですか。

問題 3. フォルダに cert というライブラリ名を割り当ててください。

 cert "/home/user/cert";

問題 4. sales_temp を一時データセットとして作成してください。

data .sales_temp;
  set cert.sales_raw;
run;

問題 5. 既存の cert.sales_raw を読み込んでください。

data work.sales_temp;
   cert.sales_raw;
run;

02

CSV・Excelファイルを読み込む

外部ファイルをSASデータセットへ変換します。読み込みに成功しても型や長さが意図と異なることがあるため、作成後の確認までを一連の操作として覚えます。

CSVファイルを読み込む — PROC IMPORT

基本形: proc import datafile="ファイルのパス" out=出力先 dbms=csv replace;

DATAFILE= に入力ファイル、OUT= に作成するSASデータセットを指定します。DBMS=CSV はファイル形式、REPLACE は同名データセットの上書きを表します。

GUESSINGROWS= は、各列のタイプと長さを推測するために確認する行数を指定します。guessingrows=max; は全行を確認する指定で、後半に長い文字列や異なる形式の値がある場合の文字切れや誤った型推測を防ぎやすくなります。ただし、大きなファイルでは読み込みに時間がかかります。

GUESSINGROWS はCSVなどの区切りファイル向けで、XLSXエンジンには使いません。

/* CSVをWORK.ORDERSとして読み込む */
proc import datafile="/home/user/source/orders.csv"
            out=work.orders
            dbms=csv
            replace;
  guessingrows=max;
run;

区切り文字を指定して読み込む — DELIMITER

基本形: proc import ... dbms=dlm; delimiter="区切り文字";

DBMS=DLMは一般的な区切り文字付きファイルを表します。DELIMITER=でパイプ、タブ、セミコロンなど、実際のファイルに使われている区切り文字を指定します。

/* パイプ区切りファイルを読み込む */
proc import datafile="/home/user/source/orders.txt"
            out=work.orders_pipe
            dbms=dlm
            replace;
  delimiter="|";
  getnames=yes;
  guessingrows=max;
run;

Excelシートを直接読み込む — PROC IMPORT

基本形: proc import datafile="Excelファイル" out=出力 dbms=xlsx replace; sheet="シート名"; run;

1つのシートをSASデータセットへ直接取り込む方法です。複数シートをライブラリのように扱う場合は、次のXLSXエンジンを使います。

/* JanuaryシートをWORKへ直接読み込む */
proc import datafile="/home/user/source/orders.xlsx"
            out=work.orders_january
            dbms=xlsx
            replace;
  sheet="January";
  getnames=yes;
run;

Excelブックをライブラリとして開く — XLSXエンジン

基本形: libname ライブラリ名 xlsx "Excelファイルのパス";

Excelブックを一時的なライブラリとして割り当てます。シート名をデータセット名として SET で読み込み、使用後は libname ライブラリ名 clear; で割り当てを解除します。

/* Januaryシートを読み込む */
libname excel xlsx "/home/user/source/orders.xlsx";

data work.orders_january;
  set excel.January;
run;

/* Excelブックのライブラリ割り当てを解除する */
libname excel clear;

読み込み結果の先頭行を確認する — PROC PRINT

基本形: proc print data=ライブラリ名.データセット名(obs=行数);

OBS= を指定すると、先頭から表示する行数を制限できます。値の並び、欠損、文字切れ、日付の見え方を少量のデータで確認します。

/* 先頭10行だけ表示する */
proc print data=work.orders(obs=10);
run;

出力例

  2  C002         2026-01-06    8300  West
  3  C003         2026-01-06       .  North

表示項目意味確認すること
Obs表示上の行番号指定した行数まで表示されているか
各変数の値読み込まれた実際のデータ欠損、文字切れ、桁ずれがないか
日付の表示日付変数に適用された表示形式文字列のまま、または数値の連番になっていないか

03

データセットを縦・横に結合する

同じ列構造のデータを行方向に追加するときは SET、共通キーを使って列方向に結合するときは MERGE ... BY を使います。

複数のデータセットを縦に連結する — SET

基本形: set データセット1 データセット2 ...;

SET に複数のデータセットを並べると、記述した順番で行が追加されます。月別データなど、列構造が同じデータの統合に使います。

/* 3か月分の売上を縦に連結する */
data work.all_sales;
  set cert.sales_jan cert.sales_feb cert.sales_mar;
run;

SETは列を増やさず、行を下へ積む

入力JAN 2行
FEB 2行
MAR 2行
→
SETset jan feb mar;
→
出力ALL_SALES 6行
同じ列構造

結合キーの順番に並べる — PROC SORT

基本形: proc sort data=入力データ out=出力データ; by キー変数; run;

MERGE ... BY を実行する前に、すべての入力データセットを同じBY変数の順番でソートします。

/* 2つのデータを同じキーで並べる */
proc sort data=cert.customers out=work.customers;
  by customer_id;
run;

proc sort data=work.all_sales out=work.sales_sorted;
  by customer_id;
run;

キーが一意なデータ同士を結合する — 1対1マージ

基本形: merge データセット1 データセット2; by キー変数;

両方のデータセットでBY変数が1行ずつなら、同じキーの2行を1行へまとめます。入力データセットは事前に同じBY変数でソートします。

/* 1顧客1行の氏名データと地域データを結合する */
data work.customer_master;
  merge work.customer_names_sorted work.customer_regions_sorted;
  by customer_id;
run;

繰り返す取引へマスタ情報を付ける — 1対多マージ

基本形: merge 多側データ 一側データ; by キー変数;

売上側に同じ顧客が複数行、顧客マスタ側に1行ある場合、マスタ側の値が同じ顧客の各売上行へ付加されます。

/* 複数の売上行へ1顧客1行の顧客情報を付ける */
data work.sales_with_customer;
  merge work.sales_sorted work.customer_master;
  by customer_id;
run;

1対多マージは、1側の情報を各取引行へ付ける

売上：多側C001・100
C001・150
＋
顧客：1側C001・East
→
結合後C001・100・East
C001・150・East
多対多マージへの注意

両方のデータセットに同じBY値が複数行ある多対多マージは、SQLの直積と同じ結果にはなりません。試験範囲の1対1・1対多を見分け、キーの重複を事前に確認します。

結合元に応じて行を残す — IN=

基本形: merge データセット1(in=フラグ1) データセット2(in=フラグ2);

IN= は、そのBYグループが各入力データセットに存在したかを示す一時フラグを作ります。両方にある行だけ残す場合は、2つのフラグを AND で結びます。

/* 両方に存在するcustomer_idだけ残す */
data work.matched_sales;
  merge work.sales_sorted(in=in_sales)
        work.customers(in=in_customer);
  by customer_id;
  if in_sales and in_customer;
run;

条件の意味と残る行

条件意味残る行
if in_sales;売上側を基準にする売上に存在するすべてのキー
if in_customer;顧客側を基準にする顧客マスタに存在するすべてのキー
if in_sales and in_customer;両方にある行だけにする双方に存在するキー

確認テスト

問題 1. 月別データを縦に連結するときに使う構文はどれですか。

問題 2. 2つのデータセットを customer_id で横に結合する構文を完成させてください。

 work.sales work.customers;
 customer_id;
run;
問題 3. IN= で作るフラグは何を表しますか。

問題 4. 売上と顧客の両方に存在する customer_id だけを残す構文を完成させてください。

data work.matched_sales;
  merge work.sales(=in_sales)
        work.customers(=in_customer);
  by customer_id;
   in_sales  in_customer;
run;

04

SASの日付・時刻・日時を読み書きする

SASは日付・時刻・日時を数値として保存します。保存値、入力時のinformat、表示時のformatを分けて考えます。

内部の数値として保存する — 日付・時刻・日時

  • SAS日付値は1960年1月1日からの日数。'01JAN1960'dは0、翌日は1。
  • SAS時刻値は午前0時からの秒数。'00:01:30'tは90。
  • SAS日時値は1960年1月1日午前0時からの秒数。定数の末尾にはdtを付ける。
/* 日付・時刻・日時の定数を内部値のまま保存する */
data work.temporal_values;
  date_value = '02JAN1960'd;
  time_value = '00:01:30't;
  datetime_value = '01JAN1960:00:01:30'dt;
run;

formatを付けない場合の値

/* 日付は日数、時刻と日時は秒数 */
date_value    time_value    datetime_value
     1             90              90

文字表現を数値として読み込む — informat

基本形: input 変数 informat.;

informatは、入力文字列をどの規則で数値へ変換するかを指定します。元の文字列の形に合うものを選びます。

/* 日付・時刻・日時の文字表現を読み込む */
data work.temporal_input;
  input order_date :date9. order_time :time8. ordered_at :datetime20.;
datalines;
30AUG2026 14:35:20 30AUG2026:14:35:20
;
run;

数値を読みやすく表示する — date/time format

基本形: format 変数 format.;

formatは保存値を変更せず、出力時の見え方だけを変えます。日付値へ日時formatを付けるなど、単位の異なるformatを混同しないようにします。

/* 日付・時刻・日時に対応する表示形式を設定する */
data work.temporal_display;
  set work.temporal_input;
  format order_date yymmdd10.
         order_time time8.
         ordered_at datetime20.;
run;

出力結果例

/* 保存値は数値のまま、表示だけが変わる */
order_date    order_time    ordered_at
2026-08-30    14:35:20      30AUG2026:14:35:20

informatは入口、formatは出口

入力文字列30AUG2026
→
informatで数値化1960-01-01からの日数
→
formatで表示2026-08-30

中央の保存値は数値のままです。formatを変更しても、保存されている日付そのものは変わりません。

05

必要な行・列を選び、型を変換する

入力時または出力時に必要な行・列へ絞り、文字と数値を明示的に変換します。

読み込み時に列を選ぶ — KEEP= / DROP=

残す列を指定: set データセット名(keep=変数1 変数2 ...);

除く列を指定: set データセット名(drop=変数1 変数2 ...);

丸括弧内にイコール付きで書く KEEP= と DROP= はデータセットオプションです。SET の入力データセットに付けると、DATAステップへ読み込む列を事前に制御できます。

/* 3列だけ読み込む */
data work.orders_selected;
  set work.orders(keep=customer_id order_date_char amount);
run;

読み込む行を条件で限定する — WHERE

基本形: where 条件式;

WHERE は入力データセットにすでに存在する変数を使い、DATAステップへ読み込む行を限定します。DATAステップ内で新しく作った変数は条件に使えません。

/* amountが0より大きい行だけ読み込む */
data work.positive_orders;
  set work.orders;
  where amount > 0;
run;

文字列を数値へ変換する — INPUT

基本形: 新しい変数 = input(文字変数, informat.);

INPUT 関数は、文字値を指定したinformatで読み取り、数値へ変換します。通常の数値文字列には comma12. など、日付文字列には yymmdd10. など、元の文字列に合うinformatを指定します。

/* "12,500"という文字列を数値12500へ変換する */
data work.orders_numeric;
  set work.orders;
  amount = input(amount_char, comma12.);

  /* "2026-08-29"という文字列をSAS日付値へ変換する */
  order_date = input(order_date_char, yymmdd10.);
run;

数値を文字列へ変換する — PUT

基本形: 新しい文字変数 = put(数値変数, format.);

PUT 関数は、数値を指定したformatで文字列へ変換します。数値のIDへ先頭の0を付ける、SAS日付値を文字列の日付へ変える、といった場合に使います。

/* 数値123を文字列"000123"へ変換する */
customer_id_char = put(customer_id, z6.);

/* SAS日付値を文字列"2026-08-29"へ変換する */
order_date_char = put(order_date, yymmdd10.);

INPUTとPUTは変換方向が反対

INPUT：文字 → 数値
"12,500"→12500
PUT：数値 → 文字
123→"000123"

覚え方は「INPUTで文字を数値として読み取る」「PUTで数値を指定形式の文字として書き出す」です。

Tips: PUTでよく使うformat

format変換例主な用途
8.12345 → " 12345"全体を8文字分の幅にし、余った左側を空白にする
8.2123.4 → " 123.40"全体を8文字分の幅にし、小数点以下を2桁にする
COMMA12.212345.6 → "12,345.60"桁区切りと小数点以下の桁数を付ける
YYMMDD10.'30AUG2026'd → "2026-08-30"SAS日付値を年月日の文字列にする
Z6.123 → "000123"先頭を0で埋めて固定桁のIDなどを作る
DATE9.'30AUG2026'd → "30AUG2026"SAS日付値を日月年の文字列にする
DOLLAR12.212345.6 → "$12,345.60"金額をドル記号付きの文字列にする

w.d の w は全体の幅、d は小数点以下の桁数です。たとえば COMMA12.2 は全体を12桁分の幅で、小数点以下2桁として変換します。

条件に合う行だけを出力する — IF

基本形: if 条件式;

サブセット化IFステートメントは、DATAステップで処理した後に出力する行を限定します。入力データに元からある変数だけでなく、DATAステップ内で新しく作った変数も条件に使えます。

/* 売上金額が10000以上の行だけ残す */
data work.large_orders;
  set work.orders;
  if amount >= 10000;
run;

値の表示形式を設定する — FORMAT

基本形: format 変数名 format.;

FORMAT は保存されている値を変えず、表示方法だけを設定します。SAS日付値に YYMMDD10. を設定すると、年月日の形式で表示されます。

/* SAS日付値を2026-08-29の形で表示する */
format order_date yymmdd10.;

出力する列を選ぶ — KEEP / DROP

残す列を指定: keep 変数1 変数2 ...;

除く列を指定: drop 変数1 変数2 ...;

DATAステップ内にイコールなしで書く KEEP と DROP はステートメントです。処理には変数を使用できますが、最終的に出力する列を制御します。

出力データセット名に data work.orders_clean(keep=...); または data work.orders_clean(drop=...); とデータセットオプションを付けても、出力列を制御できます。

/* ステートメント: イコールなし */
data work.orders_2026;
  set work.orders;
  order_date = input(order_date_char, yymmdd10.);
  format order_date yymmdd10.;
  drop order_date_char;
run;

/* 出力データセットオプション: イコールあり */
data work.orders_public(keep=customer_id order_date amount);
  set work.orders_2026;
run;

01

PROC SORT と重複削除

PROC SORT は、BY 処理、マージ、レポートの前提になります。元データを残すなら OUT= を使います。

昇順・降順に並べ替える — PROC SORT

基本形: proc sort data=入力データ out=出力データ; by 変数; run;

  • data= は入力データセット、out= はソート後に作るデータセットを指定する。
  • 何も付けないBY変数は昇順、DESCENDINGを直前に付けた変数は降順になる。
  • 複数のBY変数は左から優先され、変数ごとに昇順・降順を指定できる。
/* 商品名を降順、売上金額を昇順に並べ替える */
proc sort data=cert.orders out=work.orders_sorted;
  by descending product sales;
run;

元のデータセットをそのまま並べ替える

基本形: proc sort data=データセット名; by 変数; run;

OUT=を省略すると、DATA=で指定したデータセットが並べ替え後の内容に置き換わります。元の並びを残したい場合はOUT=を指定します。

/* WORK.ORDERS自体を顧客ID、注文日順に並べ替える */
proc sort data=work.orders;
  by customer_id order_date;
run;

重複を除く — NODUPKEY / NODUPRECS

BYキーの重複: proc sort data=入力 out=出力 nodupkey; by キー変数;

行全体の重複: proc sort data=入力 out=出力 noduprecs; by _all_;

NODUPKEYはBY変数が同じ行を1行にし、NODUPRECSは比較対象の値がすべて同じ重複行を除きます。

/* 顧客IDごとに最初の1行だけを残す */
proc sort data=work.orders_sorted out=work.unique_customers nodupkey;
  by customer_id;
run;

02

条件によって処理を分ける

IF / THEN / ELSE は条件分岐、DO / END は1つの条件で複数の処理を実行するときに使います。

条件ごとに処理を選ぶ — IF / THEN / ELSE

基本形: if 条件 then 処理; else if 条件 then 処理; else 処理;

IF の条件が成立すると THEN の後を実行します。成立しなければ、後ろの ELSE IF または ELSE へ進みます。

/* 売上金額に応じて割引率を決める */
data work.orders_discounted;
  set work.orders_sorted;
  if amount >= 10000 then discount_rate = 0.10;
  else if amount >= 3000 then discount_rate = 0.05;
  else discount_rate = 0;
run;

条件成立時の複数処理をまとめる — DO / END

基本形: if 条件 then do; 処理1; 処理2; end;

DO から END までが1つの処理のまとまりになります。ここで使う DO; は範囲を繰り返すDOループではありません。

/* 顧客IDが欠損している行へ2つの値を設定する */
data work.orders_reviewed;
  set work.orders_sorted;

  if missing(customer_id) then do;
    status = "Review";
    review_reason = "Missing ID";
  end;
  else do;
    status = "OK";
    review_reason = "";
  end;
run;

境界値を含む範囲を判定する — 比較演算子

基本形: 下限 <= 変数 and 変数 <= 上限

<／LTは未満、<=／LEは以下、>／GTは超、>=／GEは以上です。両端を含む範囲はANDで2条件を結びます。

/* 売上金額を境界値込みの3区分へ分類する */
data work.sales_ranges;
  set work.orders_sorted;
  length sales_range $ 6;
  if sales < 100000 then sales_range = "Lower";
  else if 100000 <= sales and sales <= 200000 then sales_range = "Middle";
  else sales_range = "Upper";
run;
欠損値がある場合

SASの数値欠損値は通常の数値より小さいため、最初にif missing(sales) then ...;を置かないと「100000未満」に含まれます。

03

代入文で変数を作成・更新する

代入文は右辺を計算し、その結果を左辺の変数へ保存します。新しい変数の作成、既存変数の更新、式の計算、日付定数をそれぞれ確認します。

新しい変数を作る — 代入文

基本形: 新しい変数 = 値;

左辺の変数が入力データに存在しなければ、新しい変数として作成されます。文字値は引用符で囲みます。

/* 税率という新しい数値変数を作る */
data work.orders_tax;
  set work.orders_sorted;
  tax_rate = 0.10;
run;

既存変数の値を更新する — 代入文

基本形: 既存変数 = 新しい値;

左辺の変数がすでに存在する場合は、その行の値を新しい値で上書きします。元データセットは、同じ名前で出力しない限り変更されません。

/* statusが空白の行だけUnknownへ置き換える */
data work.orders_status;
  set work.orders_sorted;
  if missing(status) then status = "Unknown";
run;

式の結果を変数へ入れる — 代入文

基本形: 変数 = 数値や変数を使った式;

右辺では四則演算や関数を使用できます。掛け算と割り算は、足し算と引き算より先に計算されます。

/* 売上金額から税込金額を計算する */
data work.orders_total;
  set work.orders_sorted;
  amount_with_tax = amount * 1.10;
run;

固定の日付を代入する — 日付定数

基本形: 日付変数 = '日月年'd;

SAS日付定数は引用符の後ろにdを付けます。日付は内部では数値として保存されるため、見やすく表示するには日付formatを設定します。

/* 2026年4月1日をSAS日付値として代入する */
data work.campaign;
  start_date = '01APR2026'd;
  format start_date yymmdd10.;
run;

04

変数の属性と表示を整える

変数の長さ、名前、ラベル、表示形式は役割が異なります。それぞれを分けて確認します。

文字変数の長さを決める — LENGTH

基本形: length 変数名 $ 長さ;

文字変数へ保存できる長さを、最初の代入より前に指定します。短すぎると値が途中で切れる原因になります。

/* region_groupを12バイトの文字変数として作る */
data work.regions;
  length region_group $ 12;
  region_group = "Kanto";
run;

変数名を変更する — RENAME=

基本形: set データセット名(rename=(変更前=変更後));

データセットオプションとして、読み込み時または書き出し時に変数名そのものを変更します。

/* 読み込み時にold_regionをregionへ変更する */
data work.orders_clean;
  set work.orders_flagged(rename=(old_region=region));
run;

変数へ説明を付ける — LABEL

基本形: label 変数名 = "表示する説明";

レポートなどに表示する説明を設定します。変数名や保存値は変わりません。

/* 金額と注文日に表示用の説明を付ける */
data work.orders_labeled;
  set work.orders_clean;
  label amount = "Order Amount"
        order_date = "Order Date";
run;

値の見え方を設定する — FORMAT

基本形: format 変数名 format.;

値の保存方法や型を変えず、画面やレポートでの表示方法だけを設定します。

/* 金額へ桁区切り、注文日へ年月日の表示形式を付ける */
data work.orders_formatted;
  set work.orders_clean;
  format amount comma12. order_date yymmdd10.;
run;

Missing Values

欠損値を含む計算は、演算子と関数で結果が変わる

数値計算では、欠損値の扱いがロジックエラーになりやすいです。+ 演算子と SUM 関数、SUM ステートメントの違いを意識します。

コード内に確認用データを入力する — DATALINES

基本形: data データセット名; input 変数名 ...; datalines; 入力データ ; run;

DATALINES は、小さな確認用データをSASコード内へ直接入力するときに使います。各行の値は INPUT に書いた変数の順で読み込まれ、データ部分は単独のセミコロンで終了します。

/* 欠損値を含む3行の確認用データを作る */
data work.missing_practice;
  input a b;
datalines;
10 5
.  7
3  .
;
run;

欠損を考慮して合計・累計する — SUM

SUM関数: 合計変数 = sum(変数1, 変数2, ...);

SUMステートメント: 累計変数 + 加算する値;

  • total_operator = a + b; は通常の足し算で、どちらかが欠損なら結果も欠損になる。
  • sum(a, b) は欠損を無視して非欠損値を合計する。
  • running_total + a; は前行までの値を保持して累計する。
/* 先ほど作ったデータで3種類の加算方法を比較する */
data work.missing_result;
  set work.missing_practice;
  total_operator = a + b;
  total_function = sum(a, b);
  running_total + a;
run;

出力結果例

/* . は数値欠損値を表す */
a    b    total_operator    total_function    running_total
10   5          15                15                10
 .   7           .                 7                10
 3   .           .                 3                13

05

グループの境界と行をまたぐ値を扱う

BY、FIRST. / LAST.、RETAIN は役割が異なります。それぞれの動きを分けて確認します。

グループ処理の単位を指定する — BY

基本形: set データセット名; by グループ変数;

BY はDATAステップでグループの境界を使うための指定です。通常は、事前に同じ変数の順で並べ替えておく必要があります。BY を書くだけでは集計されません。

/* BY処理の前に顧客ID、注文日の順で並べ替える */
proc sort data=work.orders_clean out=work.orders_by_customer;
  by customer_id order_date;
run;

/* 顧客IDをグループ処理の単位として指定する */
data work.orders_grouped;
  set work.orders_by_customer;
  by customer_id;
run;

グループの先頭と末尾を判定する — FIRST. / LAST.

基本形: first.グループ変数 ／ last.グループ変数

FIRST. と LAST. は、BY を指定したときにSASが作る一時的な自動変数です。先頭または末尾の行では1、それ以外では0になります。

/* 顧客ごとに先頭行と末尾行のフラグを付ける */
data work.orders_with_edges;
  set work.orders_by_customer;
  by customer_id;
  is_first = first.customer_id;
  is_last = last.customer_id;
run;

前の行の値を保持する — RETAIN

基本形: retain 変数名 初期値;

DATAステップ内の代入文で作る変数は、通常、次の行を処理するときに欠損値へ戻ります。RETAIN を指定すると、前の行で計算した値を次の行へ引き継げます。

/* 行を読み込むたびに連番を1ずつ増やす */
data work.orders_numbered;
  set work.orders_by_customer;
  retain row_no 0;
  row_no = row_no + 1;
run;

RETAINは前の行の値を次の行へ渡す

開始row_no = 0
→
1行目0 + 1 = 1
→
2行目へ保持1 + 1 = 2

RETAINがなければ、代入文で作ったrow_noは次の行の開始時に欠損へ戻ります。

SUMステートメントとの違い

running_total + amount; は値を自動的に保持するため、RETAIN を別に書く必要はありません。通常の代入文で累計する場合は、RETAIN が必要です。

BY Groups

first. / last. は「行」ではなく「グループ境界」を見る

first.customer_id と last.customer_id は、BY グループの始まりと終わりを示します。複数の BY 変数を使うと、どの単位で初期化するかが得点差になります。

複数のBY変数でグループ境界を作る

基本形: by 上位グループ 下位グループ;

  • by region customer_id order_date; は、地域、顧客、日付の順に並べる。
  • DATA ステップ側の by region customer_id; は、地域内の顧客単位で境界を作る。
  • first.customer_id で顧客ごとに初期化し、last.customer_id で顧客ごとの結果を出す。
/* 地域、顧客ID、注文日の順で並べ替える */
proc sort data=work.orders_clean out=work.orders_by_region_customer;
  by region customer_id order_date;
run;

/* 地域内の顧客ごとに売上と件数を集計する */
data work.region_customer_summary;
  set work.orders_by_region_customer;
  by region customer_id;
  /* 地域内で顧客が変わるたびに集計値を初期化する */
  if first.customer_id then do;
    customer_total = 0;
    customer_count = 0;
  end;
  /* 顧客単位で売上と件数を累計する */
  customer_total + amount;
  customer_count + 1;
  if last.customer_id then output;
  keep region customer_id customer_total customer_count;
run;

この例ではC001・C002をEast、C003をWestとしています。C001は100 + 150、C002は80 + 120 + 50です。途中行では累計だけを更新し、LAST.CUSTOMER_ID=1の行だけが出力されます。

読む順番

by region customer_id; の場合、顧客単位の集計なら first.customer_id で初期化します。地域全体の集計なら first.region を使うため、問題文の「単位」を先に確認します。

06

文字・数値・日付を関数で加工する

関数の種類ごとに、入力値がどのような結果へ変わるかを確認します。

文字列を取り出し・整形する — 文字関数

基本形: 新しい文字変数 = 文字関数(文字列, 引数);

  • SCAN は、区切り文字で分けた文字列から指定位置の語を取り出す。
  • SUBSTR は、開始位置と長さを指定して文字列の一部を取り出す。
  • FIND は検索文字列が始まる位置を返し、代入文の左側に書いたSUBSTRは指定部分を置き換える。
  • TRIM は末尾の空白を除き、COMPRESS は指定した不要文字を取り除く。
  • TRANWRD は文字列内の語を置き換え、UPCASE／LOWCASE は大文字・小文字をそろえる。
/* 商品コード、年月、ステータスの文字列を整える */
data work.character_functions;
  product_prefix = scan("ABC-2026-01", 1, "-");
  year = substr("20260830", 1, 4);
  sample_digits = substr("0123456789", 3, 4);
  product_trimmed = trim("Desk   ");
  york_position = find(upcase("New York"), "YORK");
  revised_code = "ABC123";
  substr(revised_code, 1, 3) = "XYZ";
  status_upper = upcase("active");
  status_lower = lowcase("ACTIVE");
  phone_digits = compress("(03) 1234-5678", "()- ");
  new_status = tranwrd("Order-Pending", "Pending", "Complete");
run;

SCANは区切った語の番号、SUBSTRは文字位置と長さ、COMPRESSは取り除く文字を指定します。

合計・平均・丸めを求める — 数値関数

基本形: 新しい数値変数 = 数値関数(数値, 引数);

  • SUM／MEAN は、欠損値を除いて合計・平均を求める。
  • ROUND は指定単位で丸め、INT は小数部分を切り捨てて整数部分を返す。
  • SMALLEST／LARGEST は、小さい順・大きい順で指定順位の値を返す。
  • RAND は乱数を生成する。再現可能にする場合は、先にCALL STREAMINITでシードを指定する。
/* 欠損を含む3つの値を集計し、値を丸める */
data work.numeric_functions;
  a = 10;
  b = .;
  c = 25;
  total = sum(a, b, c);
  average = mean(a, b, c);
  rounded = round(12356, 100);
  integer = int(12.8);
  second_smallest = smallest(2, a, c, 40);
  second_largest = largest(2, a, c, 40);
  call streaminit(12345);
  random_value = rand("uniform");
run;

出力結果例

/* SUMとMEANは欠損値bを除いて計算する */
total    average    rounded    integer    second_smallest    second_largest    random_value
  35       17.5       12400       12             25               25          0以上1未満

複数変数をまとめて指定する — 変数リスト / OF

基本形: 関数(of 変数リスト)

  • revenue: は、名前がrevenueで始まるすべての変数を表す。
  • q1-q4 は、末尾の連番が1から4までの変数を表す。
  • start--end は、データセット上で両変数の間にあるすべての変数を表す。
/* 接頭辞、連番、データセット上の位置で変数をまとめる */
data work.variable_list_totals;
  revenue2024 = 1.2;
  revenue2025 = 1.6;
  revenue2026 = 2.0;
  q1 = 10; q2 = 20; q3 = 30; q4 = 40;
  start = 5; middle = 6; end = 7;

  revenue_total = sum(of revenue:);
  quarter_total = sum(of q1-q4);
  position_total = sum(of start--end);
run;

出力結果例

/* 3種類の変数リストで、それぞれ指定された変数が合計される */
revenue_total    quarter_total    position_total
     4.8              100               18

日付と時刻を作る — MDY / TODAY / DATE / TIME

基本形: 日付変数 = mdy(月, 日, 年);

  • MDY は月・日・年からSAS日付値を作る。
  • TODAY()とDATE()は、どちらも実行日のSAS日付値を返す。
  • TIME()は午前0時から現在時刻までの秒数を返す。
/* 固定日付、実行日、実行時刻を作る */
data work.date_created;
  base_date = mdy(8, 30, 2026);
  today_value = today();
  date_value = date();
  time_value = time();
  format base_date today_value date_value date9. time_value time8.;
run;

出力結果例

/* 実行日と実行時刻の値は実行した時点で変わる */
base_date    today_value    date_value    time_value
30AUG2026    実行日         実行日        実行時刻

日付から年・四半期・月・日を取り出す

基本形: 新しい変数 = year(日付値);

YEAR、QTR、MONTH、DAYは、SAS日付値から指定した要素を数値で返します。

/* 2026年8月30日を年・四半期・月・日に分ける */
data work.date_parts;
  base_date = '30AUG2026'd;
  year_value = year(base_date);
  quarter_value = qtr(base_date);
  month_value = month(base_date);
  day_value = day(base_date);
  format base_date date9.;
run;

出力結果例

/* QTRは1から4の数値を返す */
base_date    year_value    quarter_value    month_value    day_value
30AUG2026       2026             3               8             30

日付の間隔と移動先を求める — INTCK / INTNX / DATDIF / YRDIF

期間境界数: intck("間隔", 開始日, 終了日)

日付の移動: intnx("間隔", 基準日, 移動数, "位置")

  • INTCKは月や年などの境界を何回またいだかを返し、INTNXは指定期間だけ進めた日付を返す。
  • DATDIFは2日付間の日数、YRDIFは年数を指定した基準で計算する。
/* 2つの日付の間隔と翌月初日を求める */
data work.date_intervals;
  start_date = '01JAN2026'd;
  end_date = '01JAN2027'd;
  months = intck("month", start_date, end_date);
  next_month = intnx("month", start_date, 1, "b");
  days = datdif(start_date, end_date, "act/act");
  years = yrdif(start_date, end_date, "act/act");
  format start_date end_date next_month date9.;
run;

INTCKは境界を数え、INTNXは移動先の日付を作る

intck("month", '15JAN2026'd, '10MAR2026'd)は2です。intnx("month", '15JAN2026'd, 1, "b")は翌月の先頭01FEB2026を返します。

07

マクロ変数で値を再利用する

年やライブラリ名など、プログラム内で繰り返し使う文字列を1か所で管理します。

再利用する値を定義する — %LET

基本形: %let マクロ変数名 = 値;

マクロ変数へ保存した値は、&マクロ変数名. と書いてプログラム内で参照します。同じ年やライブラリ名を何度も使う場合に便利です。

/* 再利用する年と出力ライブラリをマクロ変数に入れる */
%let target_year = 2026;
%let outlib = work;

/* 参照時は名前の前に&を付ける */
data &outlib..target_year;
  year = &target_year.;
run;
マクロ変数のドット

&outlib..target_year のようにドットが2つ見えるのは、1つ目がマクロ変数名の終端、2つ目がライブラリ名とデータセット名の区切りだからです。

2つのドットは、展開後に1つになる

定義%let outlib=work;
→
コード上&outlib..target_year
→
実行時work.target_year

08

DO ループで処理を繰り返す

回数で繰り返すDO、先頭で条件判定するDO WHILE、末尾で条件判定するDO UNTIL、ネストしたDOを分けて確認します。

同じ処理を繰り返す — DO ループ

基本形: do 変数 = 開始値 to 終了値; 処理; end;

DO から END までの処理を、指定した範囲で繰り返します。DATAステップ内で複数行を作る場合は、ループ内に OUTPUT を書きます。

/* 1月から5月まで2か月ずつ進め、月初日を作る */
data &outlib..monthly_targets;
  do month = 1 to 5 by 2;
    target_date = mdy(month, 1, &target_year.);
    output;
  end;
  format target_date yymmdd10.;
run;

出力結果例

/* OUTPUTが3回実行されるため3行になる */
month    target_date
  1       2026-01-01
  3       2026-03-01
  5       2026-05-01

条件が成立している間繰り返す — DO WHILE

基本形: do while(条件); 処理; end;

ループの先頭で条件を判定します。最初から条件が成立しない場合は、ループ内の処理を一度も実行しません。

/* 残高が1500未満の間、毎月2%ずつ増やす */
data work.savings_while;
  balance = 1000;
  month = 0;
  do while(balance < 1500);
    balance = balance * 1.02;
    month = month + 1;
  end;
run;

条件が成立するまで繰り返す — DO UNTIL

基本形: do until(条件); 処理; end;

ループの末尾で条件を判定するため、ループ内の処理は少なくとも一度実行されます。

/* 残高が1500以上になるまで、毎月2%ずつ増やす */
data work.savings_until;
  balance = 1000;
  month = 0;
  do until(balance >= 1500);
    balance = balance * 1.02;
    month = month + 1;
  end;
run;

条件を確認する位置が違う

DO WHILE：先に確認
  1. 条件が成立しているか確認
  2. 成立していれば処理
  3. 最初から不成立なら0回
DO UNTIL：後で確認
  1. まず処理を実行
  2. 終了条件が成立したか確認
  3. 最低でも1回は実行

ループの中でさらに繰り返す — ネストDO

基本形: do 外側変数=...; do 内側変数=...; 処理; end; end;

外側の1回ごとに内側のループが最後まで実行されます。2年×12か月なら24回処理されます。

/* 2026年と2027年について12か月分の行を作る */
data work.year_month;
  do year = 2026 to 2027;
    do month = 1 to 12;
      output;
    end;
  end;
run;

出力結果例

/* 2年×12か月で24行になる */
オブザベーション数    24

09

PROC TRANSPOSE でデータを縦横変換する

どの変数を値として転置し、どの値を新しい列名に使うかを指定します。

縦持ちデータを横持ちへ変える — PROC TRANSPOSE

基本形: proc transpose data=入力 out=出力; by グループ変数; id 列名にする変数; var 値を入れる変数; run;

  • BY は1行にまとめるグループ、ID は新しい列名に使う値を指定する。
  • VAR は、新しく作られた列へ格納する値を指定する。
  • PREFIX=は転置後の列名の先頭、NAME=は元のVAR変数名を保存する列名を指定する。
/* 顧客別の月別売上を縦持ちから横持ちへ変える */
proc transpose data=work.sales_long
               out=work.sales_wide
               prefix=month_
               name=source_variable;
  by customer_id;
  id month;
  var amount;
run;

IDの値が、新しい列名になる

縦持ちC001・1月・100
C001・2月・150
→
横持ちC001
month_1=100　month_2=150

BY customer_idで1行の単位を決め、ID monthの値を列名にし、VAR amountの値をセルへ入れます。

入力と出力の例

/* 入力：同じ顧客が月ごとに複数行ある */
customer_id    month    amount
C001             1       100
C001             2       150

/* 出力：月が列になり、元のVAR変数名はsource_variableへ入る */
customer_id    source_variable    month_1    month_2
C001           amount                100        150
BY を使う前提

PROC TRANSPOSE で BY を使う場合、対象データは BY 変数でソート済み、または適切にインデックス化されている必要があります。
